### Raias de Natação e Responsabilidades

| Raia | Ator/Sistema | Responsabilidades |
|------|--------------|-------------------|
| **Cliente** | Ator Primário | Seleciona período/modelo, indica outro condutor, confirma pagamento, recebe confirmação |
| **Sistema** | Locadora de Carros | Gerencia fluxo, cria reserva, calcula descontos, coordena validações e pagamento |
| **API Detran** | Sistema Externo | Valida CNH do cliente ou outro condutor no banco de dados nacional |
| **API Pagamento** | Sistema Externo | Processa transações de pagamento (Pix, Cartão à vista, Cartão parcelado) |

### Regras de Negócio (RN) Implementadas

- **RN01 - Restrição de Idade:** Cliente deve ter idade mínima de 18 anos (validado via CNH pela API Detran)
- **RN02 - Validação de CNH:** CNH deve ser válida e não expirada no momento da reserva (validação com API Detran)
- **RN03 - Métodos de Pagamento:** Sistema aceita Pix (10% desconto), Cartão à vista (5% desconto) e Cartão parcelado até 5x (sem desconto)
- **RN04 - Cálculo de Descontos:** Descontos aplicados automaticamente pelo Sistema antes de enviar para API Pagamento

### Fluxos Identificados no Diagrama

**Caminho 1 - Fluxo Principal (Sucesso):**
Cliente → Seleciona período/modelo → Disponível? SIM → Confirma sem outro condutor → Valida CNH cliente → Calcula desconto → Confirma pagamento → Pagamento aprovado → Reserva PAGA → Email enviado ✓

**Caminho 2 - Fluxo Alternativo (Outro Condutor):**
Cliente → Seleciona período/modelo → Disponível? SIM → Confirma com outro condutor → Fornece dados outro condutor → Valida CNH outro condutor → [continua como fluxo principal] → Reserva PAGA ✓

**Caminho 3 - Exceção 2a (Carro Indisponível):**
Cliente → Seleciona período/modelo → Disponível? NÃO → ❌ CANCELADO - Carro não disponível para período

**Caminho 4 - Exceção 4a (CNH Inválida):**
[Fluxo principal até validação] → CNH válida? NÃO → ❌ CANCELADO - CNH inválida ou expirada

**Caminho 5 - Exceção 6a (Pagamento Recusado):**
[Fluxo principal até pagamento] → API Pagamento aprova? NÃO → ❌ CANCELADO - Pagamento recusado
